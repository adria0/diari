# Markdown help

What you can write in a note. Preview (top right) shows it rendered.

## Headings

# Heading 1
## Heading 2
### Heading 3
#### Heading 4

## Text

**bold**, *italic* (or _italic_), ***bold and italic***
~~struck through~~, `inline code`
==highlighted== (Preview shows it as plain text)

A line break in the text is kept as it is.

## Lists

- an item
- another
  - nested (two spaces)

1. first
2. second

## Tasks

- [ ] to do
- [x] done

In Preview, tap the box to tick it.

## Links

[[Other note]] links to Other note.md; tap it in Preview to open
it, or to create it. While you type [[, names to finish it show
above the editor.
[[Other note|shown text]]
[a web page](https://example.com)
![a picture](photo.jpg)

## Quotes

> A quote.
> It goes on.

## Callouts

> [!note] A title
> A box with a title, an icon and a colour.

> [!tip]- Folded
> Starts folded: tap the title in Preview to open it.

> [!warning]+ Foldable
> Starts open, and can be folded.

Types and colours:

> [!note] note, info, todo, abstract, summary

> [!tip] tip, hint, important, success, check, done

> [!question] question, help, faq, warning, caution, attention

> [!danger] danger, error, failure, fail, missing, bug

> [!example] example

> [!quote] quote, cite
